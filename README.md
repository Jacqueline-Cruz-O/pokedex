# Pokédex

## Descripción del proyecto
La siguiente aplicación forma parte del proyecto final del bootcamp de Desarrollo Web Cohorte 35 de TRIPLE TEN, consiste en una Pokédex desarrollada con React y Vite que permite explorar información de Pokémon utilizando datos obtenidos desde la PokeAPI.

La aplicación permite buscar hasta 500 Pokémon por nombre, número de Pokédex o tipo. Los resultados se muestran en tarjetas responsivas que incluyen imagen, número, nombre y tipos del Pokémon.


## Funcionalidades

* Visualización de Pokémon en tarjetas.
* Consumo de datos desde una API third-party.
* Búsqueda en tiempo real por:
  * Nombre.
  * Número de Pokédex.
  * Tipo de Pokémon.
* Botón “Mostrar más” para cargar tres tarjetas adicionales por clic.
* Preloader durante la carga de datos.
* Manejo de errores en caso de fallo en la solicitud.
* Mensaje cuando no se encuentran resultados.
* Página 404 personalizada con enlace de regreso al inicio.
* Diseño responsive para móvil, tablet y escritorio.
* Uso de `normalize.css`.
* Fuente local integrada mediante `@font-face`.

## Rutas disponibles

* `/` — Página principal del proyecto.
* `/pokedex` — Página con la lista de Pokémon.
* `*` — Página 404 para rutas inexistentes.

## API utilizada

Este proyecto utiliza la API pública de Pokémon:

[PokeAPI](https://pokeapi.co/)

Los datos obtenidos se usan para mostrar información básica de cada Pokémon, como:

* ID
* Nombre
* Imagen
* Tipos
